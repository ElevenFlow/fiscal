Regras de uso

Segurança e decisões fiscais

Certificado A1

Nunca exibir senha, buffer PFX ou XML completo em componentes de cliente.

XML como fonte

DANFE e DANFSE são representações; o XML autorizado orienta a interface.

Estoque simplificado

Entradas via XML e devoluções precisam mostrar impacto previsto antes de salvar.

Referências consideradas: padrões de dashboards shadcn/ui, guia editorial e visual da Receita Federal, e boas práticas de design systems operacionais para interfaces de alto volume.
